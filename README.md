# ArtisaneStudio

A luxury interior design agency landing page built using pure HTML and CSS. This project was developed as a frontend practice exercise to master page layouts, custom typography, and visual hierarchy without relying on external frameworks.

## 🚀 Features
- **Elegant Hero Section:** A clean introductory fold showcasing brand identity.
- **Portfolio Gallery:** Structured layout displaying design projects.
- **Service Offerings:** Clearly separated blocks detailing agency capabilities.
- **Pricing Packages:** Organized pricing tables for potential clients.
- **Team Profiles:** Section introducing the design team.
- **Parallax Effect:** A smooth parallax background section highlighting agency achievements.

## 🛠️ Tech Stack
- **HTML:** Semantic structure.
- **CSS:** Custom styling, layout management, and parallax effects.
- **Webfonts:** Integrated typography for a premium look.

## ⚠️ Important Note
This project is currently **not responsive**. It was crafted specifically as a desktop-first layout practice to focus heavily on design implementation and absolute/relative positioning.

## 📂 Project Structure
    ├── assets/       # Images and graphic assets
    ├── css/          # Custom stylesheets
    ├── webfonts/     # Local font files
    └── index.html    # Main entry point

## 💻 How to Run
1. Clone the repository:
   git clone https://github.com/The-Real-Bedo/ArtisaneStudio.git
2. Open `index.html` directly in any modern web browser.
